# ToBot CLI

This project is the command-line entry point for the next version of ToBot.
It currently provides a small interactive shell with `help`, `exit`, and `quit`
commands. Hardware and application commands will be added as the new CLI takes
shape.

## Run

From the repository root:

```bash
dotnet run --project Tobot
```

The previous Explorer HAT demo is available in the
[v2 release](https://github.com/tscholze/dotnet-iot-raspberrypi-tobot/releases/tag/v2).
